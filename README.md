# Diego Conterno — Portfolio

Personal portfolio site. Plain HTML/CSS/JS, no build step.

## Run locally

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000.

## Editing

- **Projects & case studies:** the `PROJECTS` array at the top of `script.js`
- **Experience, lab, about, contact:** `index.html`
- **Theme colors:** CSS variables at the top of `styles.css`
- **Resume:** add `resume.pdf` to the project root
